# Sleep-EDF 小模型配对分析

完成任务 21/21，主比较已配对受试者 22/22。

固定主比较为同样使用一致性训练的有界头减去普通上下文头。目标是同一受试者、同一原始真值、同一注入位置下，距受扰片段边界 30 至不足 300 秒的未受扰时期。主干预是一个 30 秒 epoch 的 100 µV 加性噪声。

| 固定留出比较（候选 − 对照） | 估计 [95% 区间] |
| --- | --- |
| 主终点，受扰输入上的绝对错误率差 D | +1.824 pp [-0.898 pp, +5.163 pp] |
| 同一目标在未注入输入上的错误率差 C | +1.936 pp [-0.870 pp, +5.387 pp] |
| 额外错误变化的两方法差 ΔS | -0.112 pp [-0.281 pp, +0.056 pp] |
| 预测翻转率差（主窗口） | -0.112 pp [-0.337 pp, +0.112 pp] |
| 受扰 epoch 上绝对错误率差 | +0.000 pp |
| 全记录未注入 Macro-F1 差 | -1.364 pp [-2.149 pp, -0.570 pp] |

错误率差及翻转率差为负表示候选低于对照，Macro-F1 差为正表示候选更高。D = C + ΔS。翻转包含致错、纠错和错误类别之间的变化。验证集结果仅用于记录模型选择或描述。

先在受试者内对有效注入位置和随机种子取等权均值，再对受试者作 20,000 次配对 bootstrap。区间未校正多个次要比较。所有观测相等时不从经验分布推断零不确定性。根据干净宏 F1、受扰邻近区和受扰 epoch 的绝对错误共同解释。
